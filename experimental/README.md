# Experimental

This folder contains prototype and experimental work that is **not part of the main Tap DAO application**.

## Contents

| Folder | Description |
|---|---|
| `frontend-3d/` | Early 3D UI prototype using React Three Fiber, Three.js, and GSAP. Explored as an alternative kiosk UI but not integrated. Has `socket.io-client` wired in, suggesting it was meant to connect to the backend. |

These are preserved for reference — they are not started by any of the deployment scripts.
